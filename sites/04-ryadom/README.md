# Центр «Рядом» — учебный сайт

Четыре страницы: `index.html`, `services.html`, `specialists.html`, `contacts.html`.

Стек: HTML5, CSS3, JavaScript. Нет сборщика, фреймворков и сервера. Откройте `index.html` в браузере.

Форма демонстрационная — не отправляет персональные данные и не сохраняет их. Телефон и адрес вымышлены.

В `sitemap.xml` замените `example.com` своим доменом после публикации. Код легко загружать на любой бесплатный статический хостинг.

Фотография на главной — из предоставленного пользователем архива. Остальные иллюстрации сделаны CSS и векторной графикой.
