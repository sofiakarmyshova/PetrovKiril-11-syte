# Медика — учебный сайт

Четыре HTML-страницы по макету Figma Make: index.html, services.html, doctors.html, contacts.html. Чистые HTML/CSS/JS без React и бэкенда. Откройте index.html в браузере.

**Фотографии:** оба оригинальных изображения из пользовательского архива сохранены локально: `assets/doctor.jpg` и `assets/clinic.jpg`. Для отображения фотографий интернет не нужен.

Форма записи — только демонстрация, данные никуда не отправляются. Адрес, цены, контакты и врачи вымышленные.
