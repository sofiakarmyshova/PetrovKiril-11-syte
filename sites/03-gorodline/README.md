# ГородЛайн — учебный многостраничный сайт

## Содержимое

- `index.html` — главная, популярные маршруты, преимущества, оплата проезда.
- `routes.html` — поиск и фильтры 8 маршрутов, остановки и подробности.
- `schedule.html` — выбор маршрута, таблица рейсов и переключение будни/выходные.
- `contacts.html` — контакты, учебная форма, декоративная карта офиса.
- `css/style.css` — общий дизайн и адаптив под десктоп, планшет и телефон.
- `js/data.js` — данные демонстрационных маршрутов и остановок.
- `js/main.js` — интерактивное меню, поиск, расписание, форма и окна.
- `assets/bus.jpg` — оригинальная фотография из предоставленного архива.
- `assets/icons/` — локальные SVG-иконки, повторяющие оригинальную векторную графику макета.
- `robots.txt` и `sitemap.xml` — файлы для базовой SEO-подготовки.

## Как открыть

Распакуйте ZIP и откройте `index.html` в браузере. Для проверки на локальном HTTP-сервере:

```bash
python -m http.server 8000
```

Перейдите на `http://localhost:8000/`.

## Ограничения

Проект создан как демонстрационный сайт вымышленной транспортной компании. Реального транспорта, прибытия в реальном времени, отправки писем на сервер и онлайн-оплаты нет. В форме используется только проверка полей в браузере, данные никуда не передаются.

Перед публикацией на реальном поддомене замените домен `gorodline.example` в `sitemap.xml` на собственный и при желании настройте веб-аналитику (Яндекс Метрика / Google Analytics) с полученным идентификатором счётчика. Фотография находится локально и не требует внешних сервисов; Google Fonts загружается при наличии интернета и имеет системный fallback.

## Основные моменты для защиты

1. **Flexbox** используется для шапки, навигации, кнопок и небольших элементов.
2. **Grid** используется для сеток карточек и колонок страниц.
3. **Media queries** перестраивают элементы под узкий экран, включая меню и таблицу.
4. Поиск работает в `main.js`: фильтрует массив `routes` по введённому тексту и виду транспорта.
5. Расписание строится из массива остановок и демонстрационных интервалов, выбранный маршрут берётся из выпадающего списка.
6. Форма проверяет обязательные поля и выводит сообщение, но ничего не отправляет.
7. Для SEO предусмотрены семантические элементы HTML5, `title`, `description`, `alt`, `robots.txt` и `sitemap.xml`.
