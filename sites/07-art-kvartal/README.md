# АРТ.КВАРТАЛ — учебный сайт

Четыре самостоятельные страницы: `index.html`, `events.html`, `studios.html`, `contacts.html`.

## Как открыть

Распакуйте ZIP и откройте `index.html` двойным щелчком. Для локальной разработки можно использовать Live Server. Никакие сборщики, React или зависимости не требуются.

## Функциональность

- Мобильное меню и переходы между страницами;
- фильтры афиши;
- раскрытие подробностей мероприятий и студий;
- передача выбранного мероприятия/студии в форму;
- проверка имени, телефона, email, количества участников и согласия;
- демонстрационное сообщение без отправки данных.

Все мероприятия, адреса, цены, контакты и организация вымышленные. Даты событий сохранены по исходному макету Figma (октябрь–ноябрь), они НЕ являются актуальной афишей. Данные формы никуда не отправляются.

Фото из пользовательского архива находятся в `assets/`. SVG-иконки студий воспроизведены по исходным векторным элементам Figma.

Сайт адаптивен, тестовые ширины: 1440, 645, 402 и 390 px.

Файлы: HTML5, `styles.css`, `script.js`; никаких фреймворков и зависимостей.
