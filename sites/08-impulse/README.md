# ИМПУЛЬС — спортивный клуб (учебный сайт)

## Запуск
Откройте `index.html` в браузере. Сайт работает локально без npm и без сервера. Навигация организована отдельными HTML-страницами.

## Страницы
- `index.html` — главная
- `directions.html` — шесть тренировочных направлений, раскрывающиеся подробности и сравнение
- `trainers.html` — четыре тренера, описание подхода и первой тренировки
- `schedule.html` — семь дней недели, демонстрационное расписание, форма записи и схема

## Файлы
- `styles.css` — единые стили и адаптивные медиа-запросы
- `script.js` — меню, аккордеоны, расписание и форма
- `assets/athlete.jpg` и `assets/gym-interior.jpg` — фотографии из предоставленного архива
- `assets/icons/*.svg` — SVG-иконки, повторяющие соответствующие векторные слои Figma
- `robots.txt`, `sitemap.xml` — SEO. Перед публикацией **замените example.com** на реальный домен.

## Демо
Все даты, тарифы, имена, услуги и контакты вымышленные. Данные формы не сохраняются и не отправляются.

## Объяснение для защиты
1. Почему использованы Grid и Flexbox? Grid нужен для сеток карточек, Flexbox — для навигации и строк внутри элементов.
2. Как работает адаптивность? Через `@media` CSS: сетки перестраиваются, шапка показывает меню.
3. Как работает смена дня? `data-day` кнопки выбирает массив занятий; JS перестраивает список DOM.
4. Как работает выбор направления? Ссылки передают параметр `direction`, который JS ставит в `select`.
5. Как проверяется форма? HTML `required`, JS проверяет число цифр телефона, согласие и дату, а затем показывает сообщение, не отправляя данные.
6. Зачем нужны `alt`, семантические теги и meta-description? Для доступности и SEO.
