# Ритм Банк — учебный сайт

Адаптивный многостраничный сайт по макету Figma: https://www.figma.com/design/u5F5hNCu7eyUfhZTA8YIiY/Untitled?node-id=0-1

**Технологии:** HTML5, CSS3, JavaScript. Без сборщиков и фреймворков.

## Страницы

- `index.html` — главная: продукты, преимущества, этапы, FAQ.
- `cards.html` — три банковские карты и таблица сравнения.
- `deposits.html` — два вклада, таблица условий и FAQ.
- `contacts.html` — контакты, схема офиса и проверяемая форма.

## Как запустить

Самый простой способ — открыть `index.html` в браузере. Для корректного отображения внешнего SVG-спрайта и переходов между страницами рекомендуется запустить локальный сервер из папки проекта:

```bash
python -m http.server 8000
```

Открыть `http://localhost:8000`.

## Особенности

1. Навигация и ссылки между страницами работают.
2. Адаптив под телефоны, планшеты и компьютеры.
3. Мобильное меню на JavaScript и FAQ на HTML (`details/summary`).
4. Форма проверяет имя, номер телефона и сообщение; **ничего не отправляет на сервер**. Реальный банк и финансовые продукты не существуют.
5. Доступность: семантические теги, `aria`-атрибуты, фокус с клавиатуры, учёт `prefers-reduced-motion`.
6. Базовая SEO-разметка: title, description, заголовки, alt, robots.txt. После размещения нужно заменить домен в sitemap.xml и добавить URL в robots.txt.

## Публикация

Загрузить все файлы и папки в корень бесплатного хостинга. Ссылка должна вести к `index.html`. Для GitHub Pages: выбрать ветку и корневую папку в Settings → Pages. HTTPS, абсолютные пути, `robots.txt` и `sitemap.xml` проверить после назначения домена.

## Подготовка к защите

**Чем отличаются Flexbox и Grid?** Flexbox удобен для элементов в одной строке или колонке; Grid — для сеток с несколькими строками и столбцами. Например, навигация использует flex, карточки продуктов — grid.

**Что делает медиазапрос?** Правила `@media` меняют расположение и размеры блоков на разных ширинах экрана.

**Как работает форма?** JavaScript слушает `submit`, проверяет поля и показывает сообщение. Сетевой запрос не отправляется, так как проект учебный.

**Как устроен FAQ?** Элемент HTML `<details>` самостоятельно раскрывается при нажатии на `<summary>`, поэтому дополнительный JS для него не нужен.

**Для чего нужны `title` и `meta description`?** `title` задаёт заголовок страницы в браузере и поисковой выдаче; `description` описывает содержимое для поисковых систем.

**Что делают `robots.txt` и `sitemap.xml`?** Первый задаёт инструкции поисковым роботам, второй перечисляет адреса страниц для индексации.
