# ЧИСТО — учебный сайт химчистки

Пять HTML-страниц: index.html, services.html, prices.html, contacts.html, privacy.html. Основные четыре соответствуют макету Figma, дополнительная текстовая страница содержит пояснение по обработке данных.

Стек: HTML5, CSS3, JavaScript без фреймворков. Фотографии из пользовательского архива — в assets.

Запуск: откройте index.html двойным кликом или через Live Server. Навигация между страницами работает локально. Калькулятор расположен на странице цен. При нажатии «Оформить заявку» выбранная позиция и количество передаются в форму через URL-параметры. Форма не отправляет данные.

SEO: title, description, OpenGraph, robots.txt и заготовка sitemap.xml. Перед публикацией необходимо вписать реальный домен в sitemap.xml. Метрику подключайте только после размещения и с соблюдением требований к персональным данным.

Контакты и цены вымышленные; сайт — учебный.
