# Петров Кирилл — портфолио веб-проектов

[Открыть сайт](https://sofiakarmyshova.github.io/PetrovKiril-11-syte/)

10 многостраничных сайтов и портфолио. HTML, CSS, JavaScript. Макеты Figma доступны из карточек проектов. Публикация — GitHub Pages из `main`, корень репозитория.

`sites/` — проекты, `assets/` — ресурсы портфолио, `semantic-core.csv` — предварительные группы поисковых запросов по страницам (без проверки частотности в Wordstat).

Организации вымышленные. Формы работают в демонстрационном режиме. Яндекс Метрика подключена: счётчик `114111699`. GA4 пока не подключён.

Для подключения GA4 заполнить `googleMeasurementId` (`G-…`) в `assets/analytics.js`.
