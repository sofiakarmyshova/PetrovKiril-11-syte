# Тёплый угол — учебный сайт

Многостраничный адаптивный HTML/CSS/JS-проект по макету Figma.

## Страницы
`index.html`, `menu.html`, `about.html`, `events.html`, `contacts.html`.

## Запуск
Откройте `index.html` в браузере либо запустите локальный сервер: `python -m http.server 8000`.

## Для публикации
1. Загрузите содержимое папки на статический хостинг.
2. После получения домена замените `https://YOUR-DOMAIN.example` в `sitemap.xml` и `robots.txt` на реальный URL.
3. Для Яндекс Метрики/Google Analytics зарегистрируйте ресурс и вставьте собственный код счётчика только после получения реального ID и настройки уведомления о сборе данных. Не использовать выдуманные ID.
4. Проверьте страницы на фактическом домене и предоставьте ссылку преподавателю.

## Примечания
Кофейня вымышленная. Форма бронирования демонстрационная — данные никуда не отправляются. Изображения взяты из предоставленных пользователем архивов. Блок событий следует актуализировать перед публикацией.

## Проверка
- 5 HTML-страниц с навигацией
- Поиск и фильтры меню, FAQ, адаптивное меню, диалог бронирования
- SEO-описания, микроразметка CafeOrCoffeeShop, robots.txt, sitemap.xml (с плейсхолдером домена)
- Адаптивные стили и состояния клавиатурного фокуса

## Краткая подготовка к защите
1. **Зачем семантические теги?** Header, main, nav, section, article и footer помогают структурировать страницу для браузеров, доступности и поиска.
2. **Чем Grid отличается от Flexbox?** Grid удобен для двумерной сетки карточек, Flexbox — для одномерной компоновки навигации и кнопок.
3. **Как реализована адаптивность?** Media queries меняют число колонок, размер заголовков и навигацию на небольших экранах.
4. **Как работает фильтр меню?** JS сравнивает `data-category` и поисковую строку, скрывая неподходящие элементы атрибутом `hidden`.
5. **Что такое SEO?** Это меры по улучшению представления сайта в поиске: заголовки, описания, семантическая разметка, оптимизированные изображения и карта сайта.
6. **Зачем robots.txt и sitemap.xml?** Первый сообщает краулерам правила обхода, второй перечисляет адреса страниц; оба требуют настройки фактического домена.
7. **Почему форма не отправляет данные?** Проект учебный, без сервера. Обработчик предотвращает отправку и честно сообщает о демонстрационном режиме.
